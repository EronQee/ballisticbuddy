# Industry Roadmap Template v2

Use this template when the user gives a new industry and wants a full SEO roadmap.

Example industry: automotive bulletproof glass.

## First Response

Do not generate the final roadmap first. Ask intake questions.

```text
我会按交互式 SEO PRD 流程来做，不会直接幻想完整路线图。

第一步我需要确认：
1. 目标市场是哪个国家和语言？
2. 你是制造商、贸易商、安装服务商、内容站，还是联盟站？
3. 核心产品是什么？
4. 是否涉及标准或认证？
5. 目标客户是谁？
6. 是否已有竞争对手网站？
7. 是否有 Semrush / Ahrefs / GSC 数据？
8. 主要转化目标是什么？
9. 是否有子品类可以升级为独立 silo？
10. 是否要多语言版本？
11. 是否有 expert reviewer？
```

## Regulated Money Page Brief

```text
URL: /automotive-ballistic-glass/bulletproof-windshield/
Title: Bulletproof Windshield Manufacturer for Armored Vehicles
H1: Bulletproof Windshield for Armored Cars and Security Vehicles
Primary Keyword: bulletproof windshield
Secondary Keywords: armored car windshield, ballistic windshield, bulletproof car glass
Intent: commercial / transactional
CTA: Request Custom Quote

Required sections:
- Short answer / product summary
- Protection levels
- Materials and structure
- Vehicle compatibility
- Multi-series thickness and weight table
- Standards with version and jurisdiction
- Price factors linked to independent cost article
- Installation notes
- Lead time
- FAQ

Schema:
- Product
- FAQPage
- Organization
- BreadcrumbList

Author / Reviewer: qualified ballistics or compliance reviewer
Evidence: product-specific test report, lab, standard version, jurisdiction
YMYL: yes
```

  Type: ROI
  Input: vehicle count, armor cost, lifecycle, operating assumptions

  Type: install readiness
  Input: vehicle model, glass spec, installer capability

Every output must distinguish verified product data from user-provided assumptions.
