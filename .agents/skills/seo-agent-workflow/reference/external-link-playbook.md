# External Link Acquisition Playbook v2

## Goal

Make external authority acquisition a real workflow rather than a sentence about backlinks.

## Inputs

```text
competitor domains
competitor top pages
competitor referring-domain exports
brand mentions
existing data, tools, guides, comparisons, and research
industry associations, suppliers, customers, and partners
target pages and business priorities
```

## Prospect Fields

```text
prospect_url
domain
contact_or_editor
topical_relevance
audience_relevance
estimated_traffic
authority_metric
link_type
placement
target_asset
relationship_status
outreach_angle
first_contact_at
last_followup_at
result
risk_notes
```

## Link-Worthy Assets

Prioritize assets that a real editor would cite:

```text
original industry data
decision tools and calculators
specification/standards comparisons
buyer guides
cost and TCO models
original case studies
engineering process explanations
```

Each asset needs source data, capture date, author/reviewer, method, assumptions, and a maintenance owner.

## Competitor Reverse Engineering

```text
1. Export referring domains for each competitor.
2. Group by relevance, traffic, page type, and relationship.
3. Find domains linking to multiple competitors.
4. Separate editorial, supplier, partner, directory, and spam patterns.
5. Recreate the useful asset or relationship, not the link itself.
6. Map prospects to a useful target URL.
```

## Allowed Methods

```text
editorial contribution
industry association citation
customer or supplier case study
original research publication
calculator promotion
unlinked mention reclamation
broken-link reclamation
digital PR
```

## Prohibited Methods

```text
buying links
link exchanges
automated forum/Q&A links
manipulative exact-match anchor control
mass directory submission
private blog networks
bulk low-quality guest posts
```

## Monthly Measurement

```text
new referring domains
lost referring domains
qualified editorial links
asset referral traffic
target-page ranking change
assisted leads
reclamation success rate
```
